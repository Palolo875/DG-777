Avant-proposLa deux-centième page

Une lettre se juge à la deux-centième page, pas à la première. L’œil y fatigue, le gris du texte y trahit ses accidents, et un empattement trop sec finit par griffer. Marnière a été dessinée pour cette page-là : des fûts à peine évasés, une hauteur d’x franche, une italiqueitalique qui accompagne le romain sans le singer.

Ses huit graisses forment une gamme plutôt qu’une collection : le Light pour les titres courants, le Regular pour le labeur, le SemiBold pour les intertitres, le Black pour les couvertures. La version variable glisse de l’une à l’autre, de 200 à 900, sans saut1.

Les chiffres elzéviriens se fondent dans la ligne : 1789, 1871, 2026elzéviriens. Les petites capitales tiennent les sigles sans élever la voix, SNCF, UNESCOpetites capitales, et le latin étendu suit le texte partout où il va : Łódź, Győr, Brașov, Þingvellirlatin étendu.
